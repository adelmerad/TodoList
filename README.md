# 📝 Todo List App

A simple and responsive Todo List built with **React** and **TypeScript**.

## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Remove tasks (optional)
- Persist tasks using `localStorage` (optional)
- Clean UI with instant interactions

## 🛠️ Tech Stack

- React
- TypeScript
- Vite (optional if you're using it)
- CSS or Tailwind (if you’re using styling)

## 📦 Installation

Clone the repo and install dependencies:

```bash
git clone https://github.com/your-username/todo-app.git
cd todo-app
npm install
npm run dev
